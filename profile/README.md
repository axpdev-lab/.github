## Axpdev Lab

Independent software studio building open-source tools for secure file management and cloud connectivity.

### Flagship Project

**[AeroFTP](https://github.com/axpdev-lab/aeroftp)** — Cross-platform file transfer client supporting 22 protocols, AI-powered agent, and military-grade encryption. Built with Tauri (Rust) + React + TypeScript.
